# Гриль-Майстер

Казуальна головоломка про шашлики для Telegram Mini App.

Грати в браузері: https://roman-ternovyi.github.io/bbq-game/ Гравець бере шашлики з грилів і збирає замовлення: 3 однакові шашлики на тарілку. Рівні генеруються автоматично, їх кількість не обмежена.

## Що є в грі

- Генератор рівнів (`js/engine.js`): кожен рівень має фіксований seed, тому рівень N завжди однаковий. Генератор перевіряє рівень симуляцією: уважний бот без підказок грає рівень 32 рази. Генератор підбирає рівень, який бот виграє в заданій частці спроб: на рівнях 16+ це 25–50%. Кожен 5-й рівень (з 5-го) – складний.
- 24 види шашликів, намальованих у SVG (`js/art.js`). Кожен вид має свій колір і форму: шашлик, курка, креветки, кукурудза, ковбаска, овочі, маршмелоу, яблуко в карамелі, полуниця в шоколаді, броколі, печериці, чорниця, баклажан, пончик, кавун, ківі, оливки, перепелині яйця, желейні ведмедики, апельсин, банан у шоколаді, тефтелі, ананас, цукрова вата. Кожен рівень бере свій набір: 4 види на 1-му рівні, 10–11 на пізніх (від 7 до 18).
- Поле до 5 рядів грилів. Кожен рівень має своє розташування: кількість рядів, великі (3 шашлики) і малі (1 шашлик) грилі.
- Конвеєри: з 3-го рівня деякі ряди їдуть по колу через увесь екран. Швидкість росте з рівнем.
- Режими рівнів: класика, великі грилі, конвеєр, шпажки, піраміда, вежа, ромб, карусель, лійка, пісочний годинник. Новий режим з'являється на своєму рівні (4, 6, 8, 10, 13, 16, 19, 22, 26), далі режими чергуються. На початку рівня банер показує режим.
- Особливі правила (з 9-го рівня, приблизно на кожному третьому рівні): «Турбо» (швидші конвеєри), «У фользі» (наступний шар схований), «Бенкет» (4 тарілки, більше видів їжі), «Тісна решітка» (4 місця).
- Генератор сам зменшує або збільшує кількість видів їжі, щоб рівень був складним, але прохідним.
- Замовлення не завжди допомагають. З 4-го рівня частина нових тарілок просить їжу, якої немає на решітці і зверху, але яка лежить на 1–2 шари глибше. Таких замовлень приблизно 10%, на складних рівнях більше. Коли решітка майже повна, такі замовлення бувають удвічі рідше.
- Решітка на 5 місць, 3 тарілки із замовленнями. Темні шашлики позаду – наступний шар.
- Довгі рівні: 30 шашликів на 1-му рівні, 75 на 5-му, до 300 з 35-го.
- Тапи ніколи не блокуються: стан гри змінюється одразу, анімації йдуть поверх. Тап по рамці гриля або поруч теж бере найближчий шашлик.
- Підказки за монети: Назад (20), +1 місце (40), Перемішати (50), Кухар (70). Монети: 1 за кожну тарілку і 15 + 2×N за перемогу на рівні N.
- Збереження прогресу в Telegram CloudStorage (і в localStorage як резерв). Вібрація через Telegram HapticFeedback. Звуки генеруються WebAudio, файлів немає.
- Мова: українська. Англійська, якщо мова Telegram – англійська. Для перевірки: `?lang=en` або `?lang=uk` в URL.

## Запуск на комп'ютері

```bash
cd bbq_game
python3 -m http.server 8080
# відкрий http://localhost:8080
```

Збірки немає: це звичайні HTML, CSS і JS файли.

## Як додати гру в Telegram

Telegram відкриває Mini App тільки за адресою **HTTPS**. Тому спочатку гру треба викласти на хостинг.

### 1. Викласти на GitHub Pages (безкоштовно)

```bash
cd bbq_game
git init && git add . && git commit -m "Grill Master" && git branch -M main
gh repo create bbq-game --public --source=. --push
gh api -X POST repos/{owner}/bbq-game/pages -f "source[branch]=main" -f "source[path]=/"
```

Через 1–2 хвилини гра буде за адресою `https://<твій-логін>.github.io/bbq-game/`.

### 2. Створити бота

1. Відкрий [@BotFather](https://t.me/BotFather), надішли `/newbot`, дай ім'я і username боту.
2. Кнопка в меню бота: `/mybots` → твій бот → **Bot Settings** → **Menu Button** → встав URL гри і назву кнопки (наприклад, «Грати»).
3. (Необов'язково) Окремий Mini App з прямим посиланням: `/newapp` → обери бота → назва, опис, картинка 640×360 → URL гри → short name (наприклад, `grill`). Посилання буде `https://t.me/<бот>/grill`.

Тепер відкрий бота в Telegram і натисни кнопку меню.

### Оновлення гри

Після змін у файлах збільш `?v=1` у `index.html` (наприклад, на `?v=2`), щоб Telegram не брав старі файли з кешу. Потім `git commit` і `git push`.

## Структура

| Файл | Що робить |
|---|---|
| `index.html` | Розмітка, підключає Telegram SDK і шрифт Nunito |
| `css/style.css` | Увесь вигляд: гриль, тарілки, решітка, анімації |
| `js/engine.js` | Чиста логіка: генератор рівнів, стан гри, ходи, підказки, симулятор |
| `js/art.js` | SVG-картинки шашликів та іконки |
| `js/main.js` | Інтерфейс, анімації, звук, вібрація, збереження, інтеграція з Telegram |

`js/engine.js` працює і в Node.js, тому генератор можна перевіряти без браузера:

```bash
node -e "const E=require('./js/engine.js'); const d=E.generateLevel(20); console.log(d.total, d.rate)"
```
