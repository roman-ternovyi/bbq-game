# Гриль-Майстер

Казуальна головоломка про шашлики для Telegram Mini App.

Грати в браузері: https://roman-ternovyi.github.io/bbq-game/ Гравець бере шашлики з грилів і збирає замовлення: 3 однакові шашлики на тарілку. Рівні генеруються автоматично, їх кількість не обмежена.

## Що є в грі

- Генератор рівнів (`js/engine.js`): кожен рівень має фіксований seed, тому рівень N завжди однаковий. Генератор перевіряє рівень симуляцією (32 прогони) і підбирає складність. Кожен 5-й рівень (з 5-го) – складний.
- 14 видів шашликів, намальованих у SVG (`js/art.js`): шашлик, курка з цибулею, креветки, кукурудза, ковбаски, овочі гриль, маршмелоу, яблуко в карамелі, полуниця в шоколаді, люля-кебаб, печериці, лосось, баклажан, картопля з салом.
- Решітка на 5 місць, 3 тарілки із замовленнями, видно наступний шар під кожним грилем.
- Підказки за монети: Назад (20), +1 місце (40), Перемішати (50), Кухар (70).
- Збереження прогресу в Telegram CloudStorage (і в localStorage як резерв). Вібрація через Telegram HapticFeedback. Звуки генеруються WebAudio, файлів немає.
- Мова: українська. Англійська, якщо мова Telegram – англійська. Для перевірки: `?lang=en` або `?lang=uk` в URL.

## Запуск на комп'ютері

```bash
cd bbq_game
python3 -m http.server 8080
# відкрий http://localhost:8080
```

Збірки немає: це звичайні HTML, CSS і JS файли.

## Як додати гру в Telegram

Telegram відкриває Mini App тільки за адресою **HTTPS**. Тому спочатку гру треба викласти на хостинг.

### 1. Викласти на GitHub Pages (безкоштовно)

```bash
cd bbq_game
git init && git add . && git commit -m "Grill Master" && git branch -M main
gh repo create bbq-game --public --source=. --push
gh api -X POST repos/{owner}/bbq-game/pages -f "source[branch]=main" -f "source[path]=/"
```

Через 1–2 хвилини гра буде за адресою `https://<твій-логін>.github.io/bbq-game/`.

### 2. Створити бота

1. Відкрий [@BotFather](https://t.me/BotFather), надішли `/newbot`, дай ім'я і username боту.
2. Кнопка в меню бота: `/mybots` → твій бот → **Bot Settings** → **Menu Button** → встав URL гри і назву кнопки (наприклад, «Грати»).
3. (Необов'язково) Окремий Mini App з прямим посиланням: `/newapp` → обери бота → назва, опис, картинка 640×360 → URL гри → short name (наприклад, `grill`). Посилання буде `https://t.me/<бот>/grill`.

Тепер відкрий бота в Telegram і натисни кнопку меню.

### Оновлення гри

Після змін у файлах збільш `?v=1` у `index.html` (наприклад, на `?v=2`), щоб Telegram не брав старі файли з кешу. Потім `git commit` і `git push`.

## Структура

| Файл | Що робить |
|---|---|
| `index.html` | Розмітка, підключає Telegram SDK і шрифт Nunito |
| `css/style.css` | Увесь вигляд: гриль, тарілки, решітка, анімації |
| `js/engine.js` | Чиста логіка: генератор рівнів, стан гри, ходи, підказки, симулятор |
| `js/art.js` | SVG-картинки шашликів та іконки |
| `js/main.js` | Інтерфейс, анімації, звук, вібрація, збереження, інтеграція з Telegram |

`js/engine.js` працює і в Node.js, тому генератор можна перевіряти без браузера:

```bash
node -e "const E=require('./js/engine.js'); const d=E.generateLevel(20); console.log(d.total, d.rate)"
```
